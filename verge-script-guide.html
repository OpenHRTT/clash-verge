VERGE / SCRIPTING

Verge 脚本编写指南

参数、返回值与完整示例。按当前 Verge 执行接口整理。

01快速开始

本指南适用于“规则”中创建的请求、响应和定时脚本。执行接口选择 Verge；订阅配置增强的 main(config, profileName) 使用另一套接口，不适用本指南。

在“高级设置”中选择触发阶段，填写 URL 正则并粘贴代码；返回脚本详情页保存，再开启脚本。URL 正则匹配完整 URL，例如 ^https://example\.com/api/。

请求和响应脚本需流量经过本机 VPN。HTTPS 还需开启解密、将目标域名加入解密范围，并在系统安装和完全信任本机证书；使用证书固定的应用可能无法解密。

代码从上到下直接执行，无需定义 main。最小示例表示不修改、继续处理；返回普通 JS 值不会生效，必须调用 $done。

JavaScript
$done();

02运行环境与全局接口

使用 Goja JavaScript 引擎，每次执行创建独立环境。普通变量不会保留到下一次执行；跨次保存请使用 $persistentStore。

$request
当前请求对象；请求和响应阶段可用。定时阶段不存在。
$response
当前响应对象，仅响应阶段可用。
$done(object?)
提交修改并标记完成；详细字段见“返回结果”。
$httpClient
主动发送 HTTP(S) 请求，使用回调函数。
$persistentStore
按当前脚本隔离的字符串键值存储。
console.log / info / warn / error / debug
写入“规则与脚本日志”。每次最多 20 条，每条最多 4096 字节。
$notification.post(title, subtitle, body)
将三个字符串写入脚本日志，不弹出系统通知。

03请求对象 $request

下面的属性用于读取输入。修改对象本身不会自动提交；把需要修改的字段传给 $done。头名称应忽略大小写查找。

url: string
完整 URL，包括查询参数。
method: string
HTTP 方法，例如 GET、POST。
headers: object
请求头，键和值均为字符串；重复头只提供一个值。Host 不保证出现在此对象中，域名可从 url 读取。
body: string
请求正文字符串，空正文为 ""。Verge 模式在响应阶段也提供当前请求正文。

04响应对象 $response

status: number
HTTP 状态码整数，例如 200。
headers: object
响应头，键和值均为字符串；重复头只提供一个值。
body: string
响应正文字符串。处理 JSON 时用 JSON.parse 读取，修改后用 JSON.stringify 转回字符串。

05返回结果 $done

Verge 中 $done() 和 $done({}) 都表示不修改、继续处理。只接受对象或不传参数；不支持 $done("正文")。每次执行只使用第一次 $done 的结果；它不会停止后续 JS 语句，调用后不要再做可能出错的工作。

只返回需要改动的字段。headers 会替换整组头，保留原头请先复制再修改；不要手动设置 Content-Length、Transfer-Encoding、Connection 等传输头。

所有返回字段会先校验。未知字段、类型错误、超时或脚本异常会记录错误，本次 $done 修改不生效。持久存储和已发送的主动请求不会回滚。

url: string · request
改写请求 URL，只接受包含主机名的 http:// 或 https:// 地址。
method: string · request
修改请求方法，仅接受大写字母，例如 POST。
headers: object · request / response
替换当前阶段的整组头；每个值必须是字符串。
body: string · request / response
替换当前阶段正文，上限 262144 字节（256 KiB）。
status: number · response
修改响应状态码，接受 200–599 的整数。
response: object · request
直接返回本地响应，不请求上游。内层仅支持 status、headers、body；status 默认 200。不能与其他顶层字段一起返回。
abort: boolean · request / response
传 true 直接中断连接，不产生正常 HTTP 响应。

06示例：添加请求头

触发选择“请求”。复制原头后添加字段，再通过 $done 提交。

JavaScript
const headers = Object.assign({}, $request.headers);
headers["X-Verge"] = "1";
$done({ headers: headers });

07示例：修改 JSON 响应

触发选择“响应”，URL 正则限定到返回 JSON 的接口。解析失败时记录日志并放行原响应。

JavaScript
let result = {};
try {
  const data = JSON.parse($response.body);
  delete data.ads;
  result = { body: JSON.stringify(data) };
} catch (error) {
  console.log(String(error));
}
$done(result);

08示例：返回本地响应

触发选择“请求”。请求匹配后直接返回下面的 JSON，不访问原接口。

JavaScript
$done({
  response: {
    status: 200,
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ ok: true })
  }
});

09主动请求 $httpClient

支持 get、post、put、delete、head、patch、options。第一个参数可为 URL 字符串，或包含 url、headers、body 的对象；不支持其他选项。headers 的值和 body 均使用字符串。

第二个参数必须是回调 (error, response, body)。成功时 error 为 null；失败时为错误字符串，response 可能为空。response 提供整数 status 和字符串头对象 headers，body 为字符串。

回调在本次执行内完成，主动请求走当前内核网络规则。所有请求共用本次脚本的 2 秒预算，单次响应正文上限 256 KiB。在回调中调用 $done，不要在外面提前调用。

JavaScript
$httpClient.get("https://example.com/", function (error, response, body) {
  if (error) {
    console.log(error);
  } else {
    console.log(response.status);
  }
  $done();
});

10持久存储 $persistentStore

Clash Verge Plus 的数据按脚本 ID 隔离：同一脚本多次执行可共享，不同脚本即使使用同名 key 也不共享。省略 key 时使用空字符串键。普通对象请先转成 JSON 字符串再保存。

read(key?): string | null
读取字符串，键不存在或读取失败返回 null。
write(value, key?): boolean
写入字符串，单个值最多 65536 字节（64 KiB）；返回是否成功。
write(null, key?): boolean
删除对应键；返回是否成功。
JavaScript
const key = "last-run";
const previous = $persistentStore.read(key);
console.log(previous === null ? "first run" : previous);
const saved = $persistentStore.write(new Date().toISOString(), key);
console.log("saved: " + saved);
$done();

11定时脚本

执行接口选 Clash Verge Plus，触发选“定时”；界面可设置 60–86400 秒间隔，步进 60 秒。只在本机 VPN 扩展存活时运行，停止 VPN 即停止；不是独立的系统后台任务。

定时脚本没有 $request 和 $response，可使用主动请求、持久存储和日志，也必须调用 $done()。返回的请求／响应修改没有目标，不会应用。上面的存储示例可以直接用于定时脚本。

12限制与排查

Clash Verge Plus 模式每次执行超时固定为 2 秒，最多同时执行 4 个脚本。正文必须是字符串；流式、编码不支持或超过 256 KiB 的正文会使对应脚本跳过。不是所有二进制或媒体请求都能处理。

没有浏览器 DOM、fetch、XMLHttpRequest、setTimeout、setInterval，也没有 Node.js 的 require、npm、process、Buffer、文件系统或系统命令接口。请用 $httpClient 发请求；异步定时器不受支持。

$argument、$script、$environment 仅由 Surge/Stash 兼容模式提供，Clash Verge Plus 模式不提供。来源应用只是标签，不会改变 API；第三方脚本应按原平台选择兼容模式并核对支持范围。

从“规则”进入“规则与脚本日志”查看 console 输出和定时执行错误；请求／响应执行错误还可在抓包开启后的对应请求详情中查看。保存成功只说明配置和语法通过校验，实际生效需用匹配的请求验证。

执行后没有变化时，依次检查：脚本是否开启、VPN 是否运行、URL 正则和触发阶段是否正确、HTTPS 解密与信任是否完成，以及代码是否在预算内调用了 $done。

03請求對象 $request

url: string
完整 URL，包括查詢參數。
method: string
HTTP 方法，例如 GET、POST。
headers: object
請求頭，鍵和值均為字符串；重復頭只提供一個值。Host 不保證出現在此對象中，域名可從 url 讀取。
body: string

04響應對象 $response

headers: object

直接返回本地響應，不請求上游。內層僅支持 status、headers、body；status 默認 200。不能與其他頂層字段一起返回。

Clash Verge Plus Scripting Guide

Parameters, return values and complete examples for the Clash Verge Plus runtime API.

01Quick Start

This guide covers request, response and timer scripts created under Rules. Select Clash Verge Plus as the runtime API. Subscription configuration scripts using main(config, profileName) have a separate API.

In Advanced Settings, choose a trigger, enter a URL regular expression and paste your code. Return to Script Details to save, then enable the script. The expression matches the full URL, for example ^https://example\.com/api/.

Request and response scripts require traffic through the local VPN. For HTTPS, enable decryption, include the target domain, and install and fully trust the local certificate in Settings. Apps using certificate pinning may prevent decryption.

Code runs from top to bottom; no main function is needed. This minimal example continues without changes. A normal JavaScript return value does not apply changes; call $done.

JavaScript
$done();

02Runtime and Globals

Scripts run in Goja with a fresh environment for each execution. Ordinary variables do not survive between runs; use $persistentStore for persistence.

$request
The current request, available in request and response scripts. Absent in timer scripts.
$response
The current response, available only in response scripts.
$done(object?)
Submit changes and mark execution complete; see Return Values for supported fields.
$httpClient
Send HTTP(S) requests using callbacks.
$persistentStore
String key-value storage isolated to the current script.
console.log / info / warn / error / debug
Write to Rule & Script Logs. Up to 20 entries per run, each limited to 4096 bytes.
$notification.post(title, subtitle, body)
Write three strings to the script log; this does not send a system notification.

03Request Object: $request

These properties describe the input. Mutating the object alone does not apply changes; pass changed fields to $done. Match header names case-insensitively.

url: string
The full URL, including query parameters.
method: string
The HTTP method, such as GET or POST.
headers: object
Request headers with string keys and values; repeated headers expose a single value. Host may be absent; read the host from url.
body: string
The request body as a string, or "" when empty. Clash Verge Plus also exposes the current request body during the response phase.

04Response Object: $response

status: number
The integer HTTP status code, such as 200.
headers: object
Response headers with string keys and values; repeated headers expose a single value.
body: string
The response body as a string. Use JSON.parse to read JSON and JSON.stringify to serialize changes.

05Return Values: $done

In Clash Verge Plus, $done() and $done({}) continue without changes. Pass an object or no argument; $done("body") is unsupported. Only the first call is used. It does not stop later JavaScript statements, so avoid work that may fail after calling it.

Return only fields you want to change. headers replaces the entire header object; copy the original before editing to preserve other headers. Avoid setting transport headers such as Content-Length, Transfer-Encoding and Connection.

All return fields are validated before changes are applied. Unknown fields, invalid types, timeouts or script errors are logged and prevent the returned changes from applying. Storage writes and HTTP requests already sent are not rolled back.

url: string · request
Rewrite the request URL; requires an http:// or https:// URL with a host.
method: string · request
Change the request method; uppercase letters only, for example POST.
headers: object · request / response
Replace all headers for the current phase; every value must be a string.
body: string · request / response
Replace the body for the current phase; limited to 262144 bytes (256 KiB).
status: number · response
Change the response status; accepts integers from 200 to 599.
response: object · request
Return a local response without contacting the upstream. Only status, headers and body are supported inside; status defaults to 200. Cannot be combined with other top-level fields.
abort: boolean · request / response
Pass true to abort the connection without a normal HTTP response.

06Example: Add a Request Header

Select the Request trigger. Copy the original headers, add your field and submit with $done.

JavaScript
const headers = Object.assign({}, $request.headers);
headers["X-Verge"] = "1";
$done({ headers: headers });

07Example: Modify a JSON Response

Select the Response trigger and match a URL that returns JSON. If parsing fails, log the error and preserve the original response.

JavaScript
let result = {};
try {
  const data = JSON.parse($response.body);
  delete data.ads;
  result = { body: JSON.stringify(data) };
} catch (error) {
  console.log(String(error));
}
$done(result);

08Example: Return a Local Response

Select the Request trigger. Matching requests receive this JSON without contacting the original endpoint.

JavaScript
$done({
  response: {
    status: 200,
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ ok: true })
  }
});

09HTTP Requests: $httpClient

Supported methods: get, post, put, delete, head, patch and options. The first argument is a URL string or an object with url, headers and body. No other options are supported. Header values and body must be strings.

The second argument must be a callback (error, response, body). error is null on success and an error string on failure; response may be absent. response has an integer status and a string-valued headers object; body is a string.

Callbacks complete within the current execution and requests use the current core routing rules. All requests share the script’s 2-second budget; each response body is limited to 256 KiB. Call $done inside the callback, not before it.

JavaScript
$httpClient.get("https://example.com/", function (error, response, body) {
  if (error) {
    console.log(error);
  } else {
    console.log(response.status);
  }
  $done();
});

10Storage: $persistentStore

Clash Verge Plus storage is scoped to the script ID. Repeated runs share data, while different scripts using the same key do not. Omitting key uses the empty-string key. Serialize objects as JSON before storing them.

read(key?): string | null
Read a string; returns null when the key is missing or reading fails.
write(value, key?): boolean
Write a string of up to 65536 bytes (64 KiB); returns whether it succeeded.
write(null, key?): boolean
Delete the key; returns whether it succeeded.
JavaScript
const key = "last-run";
const previous = $persistentStore.read(key);
console.log(previous === null ? "first run" : previous);
const saved = $persistentStore.write(new Date().toISOString(), key);
console.log("saved: " + saved);
$done();

11Timer Scripts

Select Clash Verge Plus and the Timer trigger. The editor accepts intervals from 60 to 86400 seconds in 60-second steps. Timers run only while the local VPN extension is alive and stop with the VPN; they are not independent system background jobs.

Timer scripts have no $request or $response. They can use HTTP requests, storage and logs and must still call $done(). Returned request or response edits have no target and are not applied. The storage example above can be used as a timer script.

12Limits and Troubleshooting

Clash Verge Plus has a fixed 2-second timeout per execution and allows up to 4 simultaneous scripts. Bodies must be strings. Streaming, unsupported encodings or bodies larger than 256 KiB cause scripts to be skipped. Binary and media requests may not be processable.

There is no browser DOM, fetch, XMLHttpRequest, setTimeout or setInterval, and no Node.js require, npm, process, Buffer, filesystem or system command APIs. Use $httpClient for network requests; asynchronous timers are unsupported.

$argument, $script and $environment are supplied only in Surge/Stash compatibility modes, not Verge. Source App is just a label and does not change the API. Choose the original platform’s compatibility mode for third-party scripts and check its supported features.

Open Rules → Rule & Script Logs to view console output and timer errors. Request and response execution errors can also appear in the matching request details when capture is enabled. Saving validates configuration and syntax; verify behavior with a matching request.

If nothing changes, check that the script is enabled, the VPN is running, the URL pattern and phase match, HTTPS decryption and trust are set up, and the script calls $done within its budget.
